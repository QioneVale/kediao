# 课点 · 上课提醒

一个只管一件事的 Android 小工具：**把课表变成会响的闹钟**。

学校课表复杂（第几周上、单双周、临时换课）、课表只是一张图片、每次上课前都要翻相册 —— 这个 App 就是来解决这三件事的。

## 功能

| 功能 | 说明 |
| --- | --- |
| **AI 识图导入** | App 给一段固定提示词，复制后连同课表截图发给任意 AI，把 AI 的输出整段粘贴回来就能生成课表 |
| **按周生效** | 每门课都记录「第几周上」，过了第 8 周自动不再提醒，新开的课自动接上 |
| **课前闹钟提醒** | 默认提前 15 分钟，0–60 分钟可调（可设成上课时提醒），响铃 + 震动，锁屏也能弹 |
| **上课自动静音** | 到上课时间自动把手机切成静音，下课后恢复原来的铃声状态 |
| **课表网格** | 一周七天的可视化课表，左右切换周次，点课程可改时间、地点、周次 |
| **下一节课卡片** | 首页直接显示下一节课是什么、在哪、还有多少分钟 |
| **手动维护** | 导入识别不准时，点课程直接改；也能完全手动添加 |

## 三步导入课表

1. 打开 App → 「导入」→ 点 **复制提示词**。
2. 打开任意对话式 AI（豆包 / 通义 / Kimi / ChatGPT…），把**提示词 + 课表截图**一起发过去。
3. 复制 AI 输出的内容 → 回到 App 粘贴 → **识别预览** → **导入这些课程**。

AI 会被要求按固定格式输出：

```
课程：高等数学
星期：1
开始：08:00
结束：09:40
周次：1-8,10-16
地点：教学楼A101
教师：张三
```

解析器也兼容：只有节次没有时间（按内置作息表换算）、单双周、`1-16周`、Markdown 列表、JSON 数组等写法。

## 首次使用建议

1. 允许**通知权限**（否则收不到提醒）。
2. 允许**精确闹钟**：设置 → 权限自检 → 精确闹钟权限。
3. 允许**免打扰**：设置 → 上课自动静音 → 去开启「免打扰」权限（Android 限制，改铃声必须要有这个权限）。
4. 小米 / 华为 / OPPO / vivo：再到系统设置里允许「自启动」「后台运行」，否则锁屏久了提醒会被系统压掉。
5. 在「设置」里确认**开学第一周的周一**，App 靠它推算今天第几周。

## 构建

推送到 `main` 分支后 GitHub Actions 自动打包，产物在 Actions 的 `kediao-apk` artifact 里：

```bash
./gradlew :app:assembleDebug
```

- minSdk 26（Android 8.0+）
- targetSdk 34
- Kotlin + 原生 View，无第三方 UI 依赖

## 目录

```
app/src/main/java/com/classmate/reminder/
├── data/      Course、Store（本地持久化 + 周次计算）、作息表
├── parser/    AI 提示词、课表文本解析
├── alarm/     闹钟调度、通知、自动静音
└── ui/        课表网格、导入页、设置页、课程编辑弹窗
```
